# 警察署管轄ガイド（大阪版）

大阪府内で開業・出店する際に、管轄警察署と関連する届出・許可手続き（風俗営業、深夜酒類提供飲食店営業、警備業、探偵業、道路使用許可、車庫証明）を確認できる静的サイトです。トップページで住所（または現在地）を入力すると、その場で管轄警察署が判定されます。

将来的には京都府・兵庫県のデータも追加し、「警察署管轄ガイド（大阪・京都・兵庫版）」として提供エリアを拡大する予定です。

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成します（例：`osaka-police-guide`）。
2. このフォルダの中身一式（index.html を含むすべてのファイル）をリポジトリ直下にアップロードします。
3. リポジトリの `Settings` → `Pages` を開き、`Source` を `Deploy from a branch`、ブランチを `main`、フォルダを `/ (root)` に設定して保存します。
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` でサイトが公開されます。

## 独自ドメインへの切り替え

1. ドメインを取得したら、DNS設定でAレコード（ルートドメインの場合）またはCNAMEレコード（サブドメインの場合）をGitHub Pagesに向けます。
2. リポジトリの `Settings` → `Pages` → `Custom domain` に取得したドメインを入力します。
3. `CNAME` というファイルがリポジトリ直下に自動生成されます。
4. HTTPS化がGitHubにより自動で行われます（反映まで数時間かかることがあります）。

## 実装済み：住所からの管轄判定

`kankatsu-kensaku.html` では、大阪府条例「大阪府警察署の名称、位置及び管轄区域に関する条例」に記載された町丁目単位のデータ（`assets/jurisdiction-data.js`）をもとに、入力された住所文字列から管轄警察署を判定します。ブラウザの位置情報（Geolocation API）から現在地を取得し、OpenStreetMap Nominatim（無料の逆ジオコーディングAPI）で住所化してから同じロジックで判定する機能も備えています。

判定ロジックは `assets/jurisdiction-match.js` にあり、Node.jsでも動作確認できます（DOM非依存）。55件のテスト住所で検証済みです。

**判定できないケース**：条例上、河川・道路・水路の左岸／右岸や東西南北で境界が決まる区域（例：「安威川左岸以南」「恩智川左岸以東」）は、住所テキストだけでは機械的に判定できません。該当する可能性がある結果には注記（caveat）を表示するようにしていますが、正式な手続きの前には必ず表示された警察署への確認をお願いする設計にしています。

## 商品画像を追加したい場合

今のカードは商品名と説明文だけのシンプルな作りにしています。画像を追加したい場合は、以下の手順で行ってください。

**1. 楽天市場の商品ページで、画像のURLを取得する**

- 商品ページを開き、商品画像の上で右クリック →「画像アドレスをコピー」（Chromeの場合）を選ぶ
- URLは `https://tshop.r10s.jp/...` や `https://thumbnail.image.rakuten.co.jp/...` のような形式になっているはずです

**2. `<a class="ad-item" ...>` の中、`<span class="ad-item-name">` の**前**に、画像タグを1行追加する**

```html
<a class="ad-item" href="（アフィリエイトリンク）" target="_blank" rel="nofollow noopener sponsored">
  <img class="ad-item-img" src="（コピーした画像URL）" alt="（商品名）">
  <span class="ad-item-name">商品名</span>
  <span class="ad-item-desc">一言説明。楽天市場で見る</span>
</a>
```

`<img class="ad-item-img" src="..." alt="...">` の1行を追加するだけで、名前の上に画像が表示されます。`alt`には商品名を日本語で入れてください（画像が読み込めなかった場合の代替表示にもなります）。

**注意点**

- 画像URLは商品ページ側の都合で変更・削除されることがあります。表示されなくなった場合は、同じ手順でURLを取り直してください
- 楽天の「リンク作成」ツールでは、画像とリンクが一体になった「バナー」形式のコードも発行できます。その場合は上記の`<a>`タグごと、発行されたコードにそのまま置き換えても構いません

## 楽天アフィリエイト広告の差し替え方法

6つの手続きガイド記事（`fuzoku-eigyo.html`など）の末尾に、それぞれ2つずつ商品広告を設置しています。各HTMLファイル内を`★広告差し替え枠`で検索すると、`1-1`〜`6-2`まで12箇所の印（HTMLコメント）が見つかります。

```html
<!-- ★広告差し替え枠 1-1（ここから） -->
<a class="ad-item" href="（アフィリエイトリンク）" target="_blank" rel="nofollow noopener sponsored">
  <span class="ad-item-name">商品名</span>
  <span class="ad-item-desc">一言説明。楽天市場で見る</span>
</a>
<!-- ★広告差し替え枠 1-1（ここまで） -->
```

差し替える際は、`<a class="ad-item" ...>`から`</a>`までを、楽天アフィリエイトのリンク作成ツールで作った新しいリンクに置き換えてください。`href`の中身（リンクURL）と、`ad-item-name`（商品名）・`ad-item-desc`（一言説明）を書き換えるだけで反映されます。コメント自体（`<!-- ... -->`の部分）は消さずに残しておくと、次回また探しやすくなります。

各記事の枠番号は次の対応です。

| 番号 | 記事 |
|---|---|
| 1-1・1-2 | fuzoku-eigyo.html（風俗営業許可） |
| 2-1・2-2 | shinya-inshoku.html（深夜酒類提供） |
| 3-1・3-2 | keibigyo.html（警備業） |
| 4-1・4-2 | tanteigyo.html（探偵業） |
| 5-1・5-2 | doro-shiyo.html（道路使用許可） |
| 6-1・6-2 | shako-shomei.html（車庫証明） |

## データの出典・注意事項

- 警察署の名称・住所・電話番号：大阪府警本部公式サイト「大阪府内の警察署等のご案内」
- 各記事の内容は、風営法・警備業法・探偵業法・道路交通法・車庫法等の一般的な制度説明であり、法的助言ではありません。
- 公開前に、`about.html` の運営者情報および `privacy.html` のプライバシーポリシーを、実際の運営者情報に合わせて書き換えてください（現在はプレースホルダーです）。
- 収益化は楽天アフィリエイトのみで運用しています（Google AdSenseは使用していません）。
