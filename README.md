# 警察署管轄ガイド（大阪・京都・兵庫版）

大阪府・京都府・兵庫県内で開業・出店する際に、管轄警察署と関連する届出・許可手続き（風俗営業、深夜酒類提供飲食店営業、警備業、探偵業、道路使用許可、車庫証明）を確認できる静的サイトです。トップページで府県を選び、住所（または現在地）を入力すると、その場で管轄警察署が判定されます。あわせて、ふるさと納税の制度解説ページも掲載しています。

## GitHub Pagesでの公開手順

1. GitHubで新しいリポジトリを作成します（例：`kankatsu-guide`）。
2. このフォルダの中身一式（index.html を含むすべてのファイル）をリポジトリ直下にアップロードします。
3. リポジトリの `Settings` → `Pages` を開き、`Source` を `Deploy from a branch`、ブランチを `main`、フォルダを `/ (root)` に設定して保存します。
4. 数分後、`https://ユーザー名.github.io/リポジトリ名/` でサイトが公開されます。

## 独自ドメインへの切り替え

1. ドメインを取得したら、DNS設定でAレコード（ルートドメインの場合）またはCNAMEレコード（サブドメインの場合）をGitHub Pagesに向けます。
2. リポジトリの `Settings` → `Pages` → `Custom domain` に取得したドメインを入力します。
3. `CNAME` というファイルがリポジトリ直下に自動生成されます。
4. HTTPS化がGitHubにより自動で行われます（反映まで数時間かかることがあります）。

## 実装済み：住所からの管轄判定（大阪・京都・兵庫の3府県対応）

`index.html` のトップページで、大阪府・京都府・兵庫県のいずれかをタブで選び、住所（または現在地）を入力すると、その場で管轄警察署を判定します。仕組みは次のとおりです。

- 各府県のデータ（警察署一覧・管轄区域ルール）は、`assets/pref/` フォルダ内に府県ごとのファイルとして分かれています（例：大阪府なら `osaka-stations.js` と `osaka-jurisdiction.js`）。
- `assets/prefectures.js` が、選択された府県のデータファイルだけを動的に読み込み、`STATIONS` / `JURISDICTION_RULES` というグローバル変数に反映します（3府県分をまとめて読み込むことはしません）。
- 判定ロジック自体は `assets/jurisdiction-match.js` に1つだけあり、大阪・京都・兵庫のどのデータが読み込まれていても共通して使われます。Node.jsでも動作確認できます（DOM非依存）。
- ブラウザの位置情報（Geolocation API）から現在地を取得し、OpenStreetMap Nominatim（無料の逆ジオコーディングAPI）で住所化してから、同じロジックで判定する機能も備えています。
- `kankatsu-kensaku.html` は、住所検索機能が旧バージョンで独立したページだった頃のURLに対する互換用リダイレクトです。現在の検索機能はすべて `index.html` にあります。

**判定の精度について**：大阪府のデータ・ロジックは、条例の記載にもとづき55件のテスト住所で検証済みです。京都府・兵庫県のデータも同じ判定ロジックを使いますが、京都府のデータ（`assets/pref/kyoto-jurisdiction.js`）には「確認が取れていない組み合わせ」を示す注記（caveat）が大阪府より多く含まれています。条例上、河川・道路・水路の左岸／右岸や東西南北で境界が決まる区域（例：「安威川左岸以南」）についても、住所テキストだけでは機械的に判定できません。該当する可能性がある結果には注記（caveat）を表示するようにしていますが、正式な手続きの前には必ず表示された警察署への確認をお願いする設計にしています。

## ふるさと納税ページの広告（アフィリエイト）の貼り付け方法

`furusato-nozei.html` に、大阪・京都・兵庫の返礼品を紹介する広告枠を **9箇所**（各府県3箇所ずつ）用意しています。枠の中身は空で、「（未設定：ふるさと納税アフィリエイトのソースコードをここに貼り付けてください）」という案内文だけが入っています。特定のASP（アフィリエイトサービス）に依存しない作りなので、「テキスト＋画像」形式のコードを発行するどのアフィリエイトサービスのコードでも、そのまま貼り付けて使えます。

**貼り付け手順**

1. 利用するアフィリエイトサービスで、紹介したい返礼品（自治体）の「テキスト＋画像」形式のリンクコードを発行する
2. 発行されたソースコードを、**改変せずそのまま**コピーする
3. `furusato-nozei.html` 内を`★ふるさと納税広告枠`で検索する（大阪-1〜大阪-3、京都-1〜京都-3、兵庫-1〜兵庫-3の9箇所）
4. 該当する枠の中にある、次の1行（案内文）を、コピーしたソースコードにそのまま置き換える

```html
<p class="ad-placeholder">（未設定：...）</p>
```

サイズの指定などは不要です。貼り付けるだけで、`assets/ad-fit.js` が実際の描画結果を見て自動的に縮小してくれます（次項参照）。コメント行（`<!-- ★ふるさと納税広告枠 ... -->`）は、目印として残しておいて構いません。消しても動作に影響はありません。

**スマホでのはみ出し対策・PCでの余白対策について**

「テキスト＋画像」形式のアフィリエイトコードは、内部にpx固定のテーブルなどを含むことが多く、`max-width:100%`を当てるだけでは、テーブルのセルが（中の文字が折り返されないなどの理由で）指定より広がってしまい、右端が枠からはみ出して見えなくなることがあります。また、アフィリエイトサービスが表記する「サイズ名」（例：「240px」）と、実際に描画される横幅（画像＋テキスト＋余白を含めた合計）が一致しないこともあります（例：画像は240pxでも、コード全体としては500px超になっているなど）。

そこでこの仕組みでは、申告されたサイズは一切当てにせず、**貼り付けたコードをブラウザ上で実際に描画させたうえで、その実測サイズをもとに、広告全体を「1枚の画像」であるかのようにまるごと`transform: scale()`で縮小**します。具体的には次の3階層構造になっています。

```html
<div class="ad-slot ad-slot--furusato" data-pref="osaka">   ← 外側の枠。縮小後の実寸にぴったり合わせて幅が決まる（PCの余白対策）
  <span class="ad-region-label">...</span>
  <div class="ad-slot-frame">                                  ← 縮小後のサイズに合わせてJSが幅・高さを設定
    <div class="ad-slot-inner">
      ...ここに広告コードを貼り付け...                              ← 自然に描画されたあと、まるごと縮小される
    </div>
  </div>
</div>
```

`assets/ad-fit.js` は、貼り付けられたコードの実際の描画結果（`scrollWidth`/`scrollHeight`）を測定し、枠が使える横幅（枠自身の内側余白を正しく差し引いた値）に収まる比率まで縮小します。内部の要素を個別に縮めないので、テーブルのレイアウト崩れによるはみ出しが起きません。floatを使った広告コード（画像を左寄せ、ボタンを右寄せにするタイプなど）でも高さを正しく測れるよう、計測対象には`display:flow-root`を指定しています。

修正の確認用に、実際に崩れやすい広告コードを模したテストページ（`ad-fit-test.html`、このサイト本体には含まれません）も用意していますので、疑わしい場合はそちらで見比べてみてください。

広告枠は9箇所用意していますが、増減させたい場合は、`furusato-nozei.html` 内の `<div class="ad-slot ad-slot--furusato" data-pref="...">...</div>` のブロックをコピー／削除するだけで調整できます。

## データの出典・注意事項

- 警察署の名称・住所・電話番号：大阪府警察・京都府警察・兵庫県警察 各公式サイト
- 各記事の内容は、風営法・警備業法・探偵業法・道路交通法・車庫法・地方税法等の一般的な制度説明であり、法的助言・税務助言ではありません。
- 公開前に、`about.html` の運営者情報および `privacy.html` のプライバシーポリシーを、実際の運営者情報に合わせて書き換えてください（現在はプレースホルダーです）。
- `furusato-nozei.html` の制度解説は、ページ内に明記した基準時点の情報にもとづいています。税制は改正されることがあるため、定期的に内容の見直し・更新をおこなってください。
